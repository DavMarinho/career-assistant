# 🎯 Carla – Mentora de Carreira com IA

Carla é uma assistente de carreira com Inteligência Artificial que ajuda pessoas de qualquer área a conquistarem seus objetivos profissionais.

## ✨ O que a IA pode fazer

- 📄 Orientação sobre currículo e LinkedIn
- 🎯 Ajuda na escolha de carreira
- 💼 Preparação para entrevistas
- 🔄 Suporte em transição de área
- 📈 Dicas de crescimento profissional
- 💰 Orientação sobre negociação de salário
- 🎓 Apoio para primeiro emprego e estágios

## 🛠 Stack

| | |
|-|-|
| Framework | Streamlit |
| IA | Google Gemini 2.5 Flash |
| Deploy | Streamlit Cloud |

## 🚀 Rodando localmente

```bash
git clone https://github.com/DavMarinho/career-assistant.git
cd career-assistant
pip install -r requirements.txt
streamlit run app.py
```

Obtenha sua chave Gemini gratuita em [aistudio.google.com](https://aistudio.google.com)

## 🌐 Deploy

Hospedado no Streamlit Cloud — acesso gratuito sem instalação.
